# Portfolio component credits

- React Bits **Magnet**, David Haz: https://reactbits.dev/animations/magnet — official JSX in `src/components/portfolio/vendor/Magnet.jsx`, with settings synchronization adjusted for React's ref rules. Its MIT + Commons Clause notice is included alongside the component.
- React Bits **Model Viewer**: https://reactbits.dev/components/model-viewer — the portfolio adaptation keeps the normalized GLTF stage, automatic framing, demand rendering and soft contact shadow. It replaces free orbit gestures with a controlled scroll camera path and screen projection. Same included license notice applies.
- Motion for React: https://motion.dev/docs/react — heading reveals, project transitions, viewport reveals, spring tilt and the final screen transition.
- Lenis: https://github.com/darkroomengineering/lenis — eased wheel scrolling on the portfolio and case-study pages. Native touch scrolling stays enabled; reduced-motion users keep native scrolling. The shared controller preserves anchor history/focus and yields to the laptop's wheel gesture.

The dimensional project turntable, tuning dial, spring-loaded role passes, cable-driven skills patchboard, postcard form treatment, contextual pointer note, project system maps, case-study pages and reading navigation are original components. The project stage uses CSS perspective and eased compositor transforms, without a second WebGL scene. Phones render native role buttons; the Motion drag/spring components mount only for eligible desktop pointers. Role straps are SVG paths driven by drag MotionValues. Dragging is enabled only for fine pointers on wide screens; native buttons remain available for touch and keyboard use. All project summaries, role details and direct case-study links remain pre-rendered.


The laptop model and the hero's SVG artwork are original to this project. No paid component packs or third-party 3D models are bundled.
