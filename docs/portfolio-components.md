# Portfolio component credits

- React Bits **Magnet**, David Haz: https://reactbits.dev/animations/magnet — official JSX in `src/components/portfolio/vendor/Magnet.jsx`, with settings synchronization adjusted for React's ref rules. Its MIT + Commons Clause notice is included alongside the component.
- React Bits **Model Viewer**: https://reactbits.dev/components/model-viewer — the portfolio adaptation keeps the normalized GLTF stage, automatic framing, demand rendering and soft contact shadow. It replaces free orbit gestures with a controlled scroll camera path and screen projection. Same included license notice applies.
- Aceternity UI **3D Card**, Manu Arora: https://ui.aceternity.com/components/3d-card-effect — pointer-relative perspective tilt adapted to Motion springs, with coarse-pointer and reduced-motion handling.
- Motion for React: https://motion.dev/docs/react — heading reveals, project transitions, viewport reveals, spring tilt and the final screen transition.
- Aceternity UI **Tracing Beam**: https://ui.aceternity.com/components/tracing-beam — inspiration for the original experience rail that tracks the expanded entry, implemented with Motion.

The project X-ray slider, expanding film reel, cable-driven skills patchboard, physical build-machine keys and receipt, postcard form treatment, contextual pointer note, project system maps, case-study pages and reading navigation are original components. Their core content is pre-rendered for search engines and visitors without JavaScript.

The laptop model and the hero's SVG artwork are original to this project. No paid component packs or third-party 3D models are bundled.
